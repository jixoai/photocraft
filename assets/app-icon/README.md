# FDE2E Photocraft app icon

An original geometric F mark on a blue rounded tile, authored for this downstream.
It replaces the upstream animal artwork and is not an ArtCraft mark.

- Master: `photocraft.svg`, a 512-unit tile with 112-unit corner radius.
- Colours: `#2f7bf5` and white; no fonts or third-party assets.
- Derived PNG, ICO, ICNS and scalable theme assets use this same mark.
- Machine filenames and application IDs remain unchanged for compatibility.
- Regenerate using `packaging/icons.sh` (resvg, Cargo and macOS iconutil).

in Git history; no upstream icon artwork is shipped by this revision.
