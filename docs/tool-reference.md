# FDE2E Photocraft 工具清单

以下是工具栏及其展开菜单中可选的完整工具名称，使用英文标签便于 agent 对照命令与界面；实际显示随界面语言变化。这个清单只保证工具可选，不代表每项工具都已达到 Photoshop 行为对等，具体缺口见 [gaps.md](gaps.md)。

程序化选择工具请参考 [控制协议](control-protocol.md) 的 `ui.set`，不要把显示名称猜作命令 id。测试将本清单与 `Tool::ALL` 对照；添加或删除工具时需同时更新清单和数量。
