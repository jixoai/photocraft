## About this fork

FDE2E Photocraft is based on upstream PhotoCraft. Historical version numbers and `verified`
metadata in these inherited guides refer to upstream releases, not separate FDE2E releases.
Download and support links point to this fork; see [the fork notes](../../FORK.md).

FDE2E Photocraft is a free, open-source image editor with layers, masks, adjustment layers, layer styles, type, vector shapes and brushes. It is an alternative to Adobe Photoshop: the menus, panels, tools and shortcuts follow Photoshop's layout, so Photoshop users find things where they expect them.

It is a native app written in Rust that draws the canvas on your graphics card, works offline, and opens and saves layered PSD files. It runs on macOS, Windows, Linux and FreeBSD, and a web version runs in the browser. FDE2E Photocraft is in early alpha: much of Photoshop's feature surface exists, but it is not yet a Photoshop replacement for daily professional work. See [Can FDE2E Photocraft replace Photoshop?](faq/replace-photoshop.md).

## Independent downstream

FDE2E maintains this fork. It is based on PhotoCraft but is not an upstream official release
and does not use the upstream launcher or community channels.

## Get help

Open an issue in the [issue tracker](https://github.com/jixoai/photocraft/issues). In FDE2E Photocraft, **Help › Report an Issue…** opens the same issue tracker.
